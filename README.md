# BharatTube Android launcher

A small, separate Android launcher for https://bharattube-ashy.vercel.app/ .

## What this APK does

- Opens the existing BharatTube site in your installed browser using a Custom Tab when supported, or the browser normally otherwise.
- The address bar/browser controls may remain visible. This is not a native video player or an offline app.
- Uses browser cookies and Google sign-in instead of an embedded WebView.
- Requests no Android permissions. A browser and internet connection are required.
- Does not change the website or fix website bugs. Previously reported video playback and other website issues can still appear.

## Verification

Version 1.0, package `in.bharattube.app`, Android 6 or later.
APK build, ZIP alignment, and v1/v2/v3 signatures verified. Icon inspected.
No phone/emulator runtime test completed. Google login, video playback, upload and installed-app launch are not verified on a phone.

The APK is a prerelease for device testing, not a claim of a fully tested native app.
The private signing key is not stored in this repository.

## Install

Download the APK from Releases. Open it on Android, allow installation from the downloading app if Android asks, then tap Install. Turn that install permission off afterward. Do not disable Play Protect. If Android shows an error or warning, keep its exact text or take a screenshot before continuing.
